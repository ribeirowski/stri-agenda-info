Privacidade e uso de dados

Esta descrição se aplica ao programa pessoal STRI Agenda e à sua rotina de sincronização.

Dados utilizados e finalidade

O programa lê o cronograma acadêmico e referências fornecidas pelo titular para obter disciplinas, datas, horários, salas e professores. Pela API do Google Calendar, cria uma agenda dedicada e consulta os eventos gerenciados nela para adicionar, corrigir ou remover atividades de acordo com o PDF.

Os dados recebidos do Google são utilizados exclusivamente para a sincronização autorizada. Não são vendidos, usados em publicidade, cedidos a corretores de dados nem utilizados para treinar modelos de inteligência artificial. Seu uso respeita a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Autorização e armazenamento

A permissão solicitada é https://www.googleapis.com/auth/calendar.app.created. O token OAuth é salvo em arquivo local e, para a execução diária, em um secret do GitHub Actions. O token não deve ser incluído no código-fonte, em logs ou neste site.

O código, as referências e o estado da sincronização ficam em um repositório privado controlado pelo titular. O estado registra as atividades, seus identificadores, as alterações e as operações pendentes. Os eventos ficam na conta Google do titular. Durante a execução, o GitHub processa os dados necessários à integração com o Google.

Retenção e controle

O histórico operacional compacto mantém até 90 execuções, e as prévias no GitHub Actions têm retenção de três dias. O histórico de versões Git pode conservar estados anteriores até que o titular os exclua. Os arquivos locais permanecem até sua remoção pelo titular.

O titular pode interromper a rotina, revogar o acesso nas configurações da conta Google, remover o token local e os secrets do GitHub e excluir a agenda dedicada. A revogação impede novos acessos, mas não apaga automaticamente os eventos já criados ou o histórico armazenado.

Esta página

Estas páginas não contêm formulários, anúncios ou ferramentas de análise. O provedor de hospedagem pode processar registros técnicos de acesso conforme sua própria política. Nenhum evento, arquivo de contatos ou credencial é publicado aqui.

Contato

O titular administra a instalação. O mantenedor é identificado pelo perfil ribeirowski no GitHub. O e-mail de suporte da instalação é exibido na configuração de autorização do Google. Não envie credenciais ou dados de agenda em canais públicos.
